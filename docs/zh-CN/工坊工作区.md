# 统一 Studio 工作区架构

YK-PETS Studio 使用同一个产品壳和四个独立路由：`/studio/appearance`、`/studio/motion`、`/studio/props`、`/studio/library`。`/studio` 只兼容跳转。四个工作区共享本地资产选择、视角和背景，但各编辑器撤销栈独立。

## 资产边界

- 外观：基础结构、颜色和静态默认姿态；
- 动作：相对语义姿态、毫秒时间、循环、插值和道具依赖；
- 道具：资产类型、默认挂载、组件层级和锚点。

动作不得修改外观配方；动作引用稳定道具 ID，不直接修改道具定义。

## 当前能力

- 完整外观工坊无损迁移；
- 同一宠物拥有独立持久化的简单/复杂模型容器；简单模型默认就绪，复杂模型状态区分未创建、草稿、就绪和需修复；
- Studio 顶部提供全局简单/复杂模型模式；首次切换复杂模式时系统自动建立非破坏性草稿，不要求额外确认，也不会覆盖简单模型；
- 外观、动作、道具三个工坊共享模型模式，资产库展示真实变体状态；复杂骨骼渲染器完成前，画布明确标记为简单模型兼容预览；
- 动作资产 v2、独立草稿、撤销重做、播放指针和播放控制；
- 关键帧写入、删除、复制、粘贴、移动、多选和 `step`/`linear`；
- 每帧一次语义姿态求值并通过唯一正式 Cloud Fox 渲染器预览；
- 外观、动作、道具三个工坊共享预览方向控制：拖动画布可自由旋转，点击正面、左侧、背面或右侧会先清除自由旋转偏移，再切换到准确的固定视角；
- 三个工坊复用同一预览控制栏，按“固定视角”和“预览变换”分组提供背景、40%–120% 缩放、三轴角度和一键复位；动作工坊在相同布局中额外显示预览时间；
- 外观工坊新增开心、生气、委屈、惊讶、爱心和眩晕眼，以及猫系、水晶和星光鼻；全部样式继续使用统一参数化头部表面挂载；
- 动作 Rig 新增头部、眼睛、瞳孔、眼距、鼻部、嘴部曲线、尾巴长度/蓬松和触角发光等动作安全通道，并复用当前帧、已选关键帧与整段动作编辑命令；
- 资产库提供 6 个只读长编排动作和 6 个内置道具，复制后进入用户资产；动作时长为 8–12 秒，每个模板包含 15–16 个语义通道和 163–272 个关键帧，并按准备、主段、转场、高潮和收势组织；星云棍术组合和星光摆胯舞可直接预览内置长棍与双荧光棒；
- 道具资产、类型、默认挂载、锚点和层级基础；
- 资产库查看、上下文编辑和删除。

## 尚未完成

道具事件轨道、同场景实例预览、版本化组件树、几何、材质、内部锚点编辑和当前程序化模型的高级动画工具已经完成。

双模型第一阶段只完成资产容器、全局模式、自动复杂草稿、状态展示和统一预览适配入口。以下复杂模型能力尚未完成：

- GLB 蒙皮模型导入和版本化保存；
- 骨骼层级、蒙皮权重、Morph、材质槽位和 Socket 校验；
- Quaternion 动画 Clip、动作重定向、运行时 IK、足底锁定和 Root Motion；
- 复杂动作时间轴、骨骼直接操控和自动动作初稿；
- 由速度、接触、命中和轨迹驱动的确定性特效；
- 简单/复杂动作双变体、降级草稿和独立发布检查。

在这些能力完成前，复杂模式不得替换现有简单模型正式渲染路径。

## 安全边界

没有新增 Chrome 权限、网络上传、后台轮询、WebSocket 或宿主网页持久配置 DOM。
