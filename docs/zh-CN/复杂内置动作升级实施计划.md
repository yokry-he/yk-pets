# 复杂内置动作升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 6 个短小、单一往复的内置动作升级为 7–12 秒、具有完整动作阶段和全身协调的舞蹈、武术与运动编排。

**Architecture:** 保持 `StudioMotionAssetV2` 与语义 Rig 不变，在内置动作域模块中用确定性的轨道构建函数组织非均匀关键帧。测试从资产合法性扩展到编排复杂度门禁，确保以后不会再次退化为短循环。

**Tech Stack:** TypeScript、Vue 3、Nuxt 4、`@yk-pets/pet-core` 语义动作系统、Node.js 合约测试。

```ts
for (const motion of BUILT_IN_STUDIO_MOTIONS) {
  assert.ok(motion.durationMs >= 7000, `${motion.id} 时长至少为 7 秒`)
  assert.ok(motion.tracks.length >= 10, `${motion.id} 至少使用 10 个语义通道`)
  assert.ok(motion.tracks.reduce((sum, item) => sum + item.keyframes.length, 0) >= 45, `${motion.id} 至少包含 45 个关键帧`)
  assert.ok(new Set(motion.tracks.flatMap(item => item.keyframes.map(keyframe => keyframe.timeMs))).size >= 12, `${motion.id} 至少包含 12 个编排时刻`)
}
```

- [ ] **Step 2: 为循环动作加入无缝首尾断言**

```ts
for (const motion of BUILT_IN_STUDIO_MOTIONS.filter(item => item.loopMode === 'loop')) {

    assert.equal(motionTrack.keyframes[0]?.timeMs, 0)
    assert.equal(motionTrack.keyframes.at(-1)?.timeMs, motion.durationMs)
    assert.equal(motionTrack.keyframes[0]?.value, motionTrack.keyframes.at(-1)?.value)
  }
}
```
