# 统一 Studio 工作区人工验收

自动 CI 不能替代真实浏览器布局、导航和 WebGL 验收。

## 路由与外观

- 打开 `/studio` 确认跳转到 `/studio/appearance`；
- 在四工作区切换、后退和前进；刷新任一工作区，确认选择正确恢复；
- 检查 760、920、1180、1440、1920 像素布局；
- 确认完整外观编辑、导入导出、撤销重做和扩展同步仍可用。

## 三个工坊的预览方向

- 分别进入外观、动作和道具工坊，在宠物预览区域水平与垂直拖动，确认宠物可连续自由旋转；
- 自由旋转后依次点击正面、左侧、背面、右侧，确认每次都直接到达对应固定视角，不叠加此前拖动偏移；
- 在任一固定视角处再次拖动，然后重复点击当前已激活的同名按钮，确认仍会清除偏移并回到准确固定视角；
- 确认外观热点、动作直接操控区和道具挂载提示不被旋转手势遮挡，窄屏下预览区不产生横向溢出。
- 确认三个工坊控制栏都清晰分成固定视角和预览变换两层，背景、缩放、X/Y/Z 与复位的位置一致；动作工坊仅多出预览时间。
- 在 760、920、1180 和 1920 像素宽度检查控制栏换行，确认不遮挡宠物、不覆盖动作直接操控区且不产生横向滚动。

## 动作工坊

- 新建动作并确认稳定 ID；
- 修改名称、时长、FPS 和循环方式；
- 写入根节点、身体、头、四肢、耳朵、眼嘴、尾巴和触角关键帧；
- 验证删除、复制、粘贴、拖动、多选、撤销和重做；
- 验证 FPS 吸附与精确毫秒输入；
- 验证 `once`、`loop`、`ping-pong` 播放；
- 保存、刷新并确认动作恢复；
- 确认身体与肚皮同步，未写入通道继续呼吸、眨眼和跟随视线；
- 确认三十个内置动作无回归。
- 选择头部、眼睛与嘴部、鼻子和尾巴，分别在多个播放头位置写入比例、眼距、表情倾斜、嗅闻、发光、嘴部曲线、尾长和蓬松关键帧，确认播放时平滑变化且停止后恢复基础外观；
- 复制并播放元气踏步舞（8 秒）、星光摆胯舞（10 秒）、马步组合拳（8.4 秒）、星云棍术组合（12 秒）、灵巧体操组合（8.8 秒）和冲刺急停挑战（9.2 秒）。每个动作至少观察准备、主段、转场、高潮和收势，确认身体重心、头部、四肢、耳尾、视线与表情协调变化，且发力点和保持段速度有明显差异。

## Root Motion 与运动特效

- 本批已于 2026-07-29 在 Chromium 1440×900 与 760×900 分别执行并记录到 `.ai/visual-cases.json`；后续修改 Root Motion、VFX、设置面板或工作区布局时，应按下面步骤重复验收。
- 复杂模式播放“行走循环”至少两个周期，确认跨循环连续移动、步幅随体型变化、支撑脚无明显水平滑动；暂停后位置保持，恢复后从原请求时间接续，停止后整体位置、转向和足底锚点归零。
- 播放“冲刺急停挑战”，确认起步加速、速度拖尾、`6300→8300ms` 制动、急停火花和重心回正；反复播放不得持续增加场景对象或产生旧火花。
- 播放“起跳与落地”，确认双脚释放、弹道连续、落地压缩、落地环与尘点各只触发一次；从落地后回拖到起跳前不得生成反向速度、重复落地特效或残留足底锚点。
- 在播放、暂停和停止状态切换动作，确认旧位移、旧速度和旧粒子均被清理；切换到简单模式后不得创建复杂 Root Motion、混合 IK 或 VFX 控制器，切回复杂模式后使用当前动作重新建立唯一控制器。
- 在动作属性“基础”页操作原地/实际移动、自动特效和恢复推荐值，确认一次操作只产生一个撤销项，保留 contacts、events、动作来源和未知扩展；窄属性栏在 360px 以下按容器宽度单列重排且无横向溢出。
- 两个视口都检查 `scrollWidth === clientWidth`、Canvas 与浮动按钮不遮挡关键控制、控制台无 error 且无 hydration mismatch。Chromium 结果不能替代 Safari/Firefox、不同 GPU/WebGL、高细节拓扑和最终像素验收。

## 高级编舞与持械动作适配

- 本批已于 2026-07-29 在 Chromium 1440×900 与 760×900 执行，证据记录到 `.ai/visual-cases.json` 的 `biped-pet-nebula-staff-adaptation`；后续修改动作适配、道具 Rig、副手约束、武器 VFX 或工作区布局时必须重复本节。
- 新复制“星云棍术组合”并切换复杂模式，不做任何骨骼、蒙皮、道具 Rig 或粒子配置。依次定位 `450/2100/3800/6100/8500/9700/11200ms`，确认准备、棍花、换手、横扫、腾空、下劈、收势均有区别，主手不脱棍，副手只在换手/横扫/下劈三段加入。
- 在棍花、横扫和腾空检查轨迹跟随真实棍端；在 `9700ms` 检查下劈端点附近同时出现青白冲击环与黄色火花。向前播放跨过命中时刻只能触发一次；暂停重复帧、首帧、向上运动和 `9700→2100ms` 回拖不得制造新命中或残留旧效果。
- 播放跨全部阶段，确认暂停冻结、恢复接续、停止归零；从下劈回拖到棍花后再向前播放，主手、副手、轨迹和命中均从当前时间重新建立。简单/复杂模式必须互斥，Canvas 始终为 1。
- 1440×900 检查七个时间点、完整持械和特效画面；760×900 检查工具栏换行、自动适配摘要与技术信息单列、浮动按钮不遮挡主要操作，并确认 `scrollWidth === clientWidth`。干净标签页 console error 与 hydration mismatch 应为 0。
- 本节通过只代表低细节双足萌宠和星云棍术纵向样板。Safari/Firefox、其他 GPU/WebGL、高细节拓扑、最终像素/性能、舞蹈/组合拳/体操/冲刺完整动作库、四足与机甲仍需独立验收。

## 道具和资产库

- 道具基础资产、默认挂载和四锚点继续可用；
- 道具事件和道具实体编辑已经实现，但不得把真实浏览器/WebGL、深度排序或高级动画工具描述为已验收；
- 删除道具清理动作依赖，删除当前资产清理共享选择。
- 确认资产库展示星云长棍、能量剑、星光折扇、双荧光棒、星云飘带和能量球；复制后应进入道具工坊且不修改原模板；
- 播放星云棍术组合与星光摆胯舞，确认内置长棍和双荧光棒在正式预览场景中出现、挂载，在多个高潮时刻改变发光和粒子强度，并在结束时按事件销毁。

## 表情造型

- 在所有六种头型上切换开心弯月、生气锐角、委屈下垂、惊讶圆睁、爱心和眩晕旋涡眼，检查正面与左右侧面可见性；
- 切换猫系、水晶和星光鼻，检查鼻子与口鼻表面贴合、发光和动作缩放；
- 确认旧眼鼻样式、眨眼、左右眼独立闭合和视线通道没有回归。

## 本地、安全与性能

- 验证 v1→v2 迁移、刷新恢复和 v1 回滚数据仍存在；
- 确认无新增上传、轮询、WebSocket 和扩展权限；
- 多次切换工作区，确认不累积多个 WebGL 场景；
- 真实 Chrome Side Panel、GPU/WebGL 深度排序和最终像素仍需单独验收。
