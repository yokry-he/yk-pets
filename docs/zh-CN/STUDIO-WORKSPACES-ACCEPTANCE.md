# 统一 Studio 工作区人工验收

自动 CI 不能替代真实浏览器中的布局、导航和 WebGL 验收。

## 路由与导航

- 打开 `/studio`，确认只跳转到 `/studio/appearance`；
- 在外观、动作、道具和资产库之间切换，确认 URL 与高亮工作区一致；
- 使用浏览器后退和前进，确认工作区与上下文正确恢复；
- 刷新任一工作区，确认当前动作和道具选择不会丢失；
- 在 760、920、1180、1440 和 1920 像素宽度检查顶层导航，不得遮挡工作区主操作。

## 外观工坊迁移

- 确认现有身份、头部、身体、前后爪、肚皮、尾巴、触角、颜色、发光、标志和检查工作区均存在；
- 保存、导入、导出、撤销、重做、随机、经典对比和本地方案继续可用；
- `/studio/appearance` 中的模型、动作测试和四视角表现应与迁移前一致；
- 顶层 Studio 壳不得再次显示网页宠物覆盖层。

## 动作工坊基础

- 新建动作后确认生成稳定 ID；
- 修改中英文名称、总时长和循环方式，刷新后仍然保留；
- 从资产列表选择不同动作，顶部共享上下文同步更新；
- 前、左、后、右视角能切换，并继续使用当前外观；
- 时间轴刻度随总时长变化；
- 当前阶段不得误导用户已经可以写入关键帧或播放自定义动作。

## 道具工坊基础

- 新建组合道具和效果道具后确认生成稳定 ID；
- 修改名称、类型和默认挂载点，刷新后仍然保留；
- 内部锚点至少显示 origin、grip、display 和 emitter；
- 点击“在动作工坊中测试”后进入动作路由，并保留当前道具上下文；
- 当前阶段禁用的几何按钮不得表现为已经可编辑。

## 资产库

- 资产库显示当前外观、三十个内置动作数量、自定义动作和自定义道具数量；
- 动作和道具的编辑按钮进入正确路由并选中对应资产；
- 删除道具后，引用该道具的动作依赖应被移除；
- 删除当前选中的动作或道具后，顶层上下文应回到“未选择”。

## 本地、安全与性能

- 打开开发者工具确认没有新增上传请求、轮询和 WebSocket；
- 确认扩展权限没有变化；
- 多次切换工作区，确认不会累积多个持续运行的 WebGL 场景；
- 检查键盘焦点、链接名称、按钮状态和窄屏纵向滚动；
- 开启减少动态效果后，顶层导航和页面切换仍可正常使用。
