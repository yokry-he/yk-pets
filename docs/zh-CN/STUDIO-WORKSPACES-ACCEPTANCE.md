# 统一 Studio 工作区人工验收

自动 CI 不能替代真实浏览器布局、导航和 WebGL 验收。

## 路由与外观

- 打开 `/studio` 确认跳转到 `/studio/appearance`；
- 在四工作区切换、后退和前进；刷新任一工作区，确认选择正确恢复；
- 检查 760、920、1180、1440、1920 像素布局；
- 确认完整外观编辑、导入导出、撤销重做和扩展同步仍可用。

## 动作工坊

- 新建动作并确认稳定 ID；
- 修改名称、时长、FPS 和循环方式；
- 写入根节点、身体、头、四肢、耳朵、眼嘴、尾巴和触角关键帧；
- 验证删除、复制、粘贴、拖动、多选、撤销和重做；
- 验证 FPS 吸附与精确毫秒输入；
- 验证 `once`、`loop`、`ping-pong` 播放；
- 保存、刷新并确认动作恢复；
- 确认身体与肚皮同步，未写入通道继续呼吸、眨眼和跟随视线；
- 确认三十个内置动作无回归。

## 道具和资产库

- 道具基础资产、默认挂载和四锚点继续可用；
- 道具事件轨道已经实现，但不得把道具几何、材质、层级和锚点实体编辑描述为已完成；
- 删除道具清理动作依赖，删除当前资产清理共享选择。

## 本地、安全与性能

- 验证 v1→v2 迁移、刷新恢复和 v1 回滚数据仍存在；
- 确认无新增上传、轮询、WebSocket 和扩展权限；
- 多次切换工作区，确认不累积多个 WebGL 场景；
- 真实 Chrome Side Panel、GPU/WebGL 深度排序和最终像素仍需单独验收。
