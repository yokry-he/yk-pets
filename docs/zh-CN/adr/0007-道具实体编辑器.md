# ADR 0007：版本化道具实体与参数化编辑器

- 状态：Accepted
- 日期：2026-07-25

## 背景

动作事件已经能够引用稳定道具 ID，但旧道具资产只有名称、类型和锚点名称，无法描述真实几何、材质或层级。

## 决策

1. 道具资产使用 schema v2，包含参数化组件树、局部变换、材质和 `origin`、`grip`、`display`、`emitter` 四个内部锚点。
2. 支持球体、方块、圆柱、圆锥、圆环、胶囊、晶体、文字牌和粒子组件。
3. 最多保存 48 个组件、240 个粒子和 48 字符文字；规范化器清理重复 ID、无效父节点与层级环。
4. 旧元数据在本地加载时迁移成版本化实体，保留稳定资产 ID 和动作依赖。
5. 道具模型只在现有 `CloudFoxStudioCanvas` 中渲染；道具工坊和动作事件预览复用同一模型组件。
6. JSON 导入导出只处理本地参数化数据，不上传远程服务。

## 结果

道具工坊可真实编辑组件树、几何、材质、内部锚点、复制和导入导出。真实浏览器/WebGL、深度排序和多设备性能仍需人工验收。
