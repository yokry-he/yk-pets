# ADR 0009：动作身体部件直接操控与整段修正

- 状态：Accepted
- 日期：2026-07-25

## 背景

逐通道下拉框适合精确调参，但不适合作为主要动作创作入口。用户需要像外观工坊一样先选择整只宠物或身体部件，再进行移动、旋转、缩放和语义调整，同时要区分当前帧、已选关键帧和整段动作。

## 决策

1. 在 `@yk-pets/pet-core` 建立唯一身体部件与控制注册表，所有控制继续引用 `cloud-fox-semantic-rig/v1`，不保存 Three.js 节点路径。
2. 支持 `current-frame`、`selected-keyframes`、`entire-motion` 三种作用范围。
3. 整段动作调整写入优先级 100 的独立 additive `clip-adjustment` 层，不改写原始关键帧。
4. 根节点和身体支持移动、旋转、等比及高级分轴缩放；其他部件只开放现有语义 Rig 能安全表达的控制。
5. 左右前后爪、耳朵和触角通过稳定通道镜像规则提供对称编辑。
6. 预览上提供轻量拖拽操控板；真正的模型射线拾取和三轴 3D Gizmo 后置到浏览器验收后的独立批次。

## 结果

- 动作仍是相对于外观的语义偏移，可复用于不同外观。
- 一次拖拽只产生一个撤销检查点。
- 不新增渲染器、Canvas、网络上传、轮询或权限。
