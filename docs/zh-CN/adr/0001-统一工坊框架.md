# ADR 0001：统一 Studio 壳与独立路由

- 状态：Accepted

## 背景

外观、动作和道具编辑拥有不同的交互模型。将全部能力堆入一个页面会混淆导航、检查器、撤销和保存语义；完全拆成独立产品又会丢失当前宠物和资产上下文。

## 决策

使用同一个 YK-PETS Studio 产品壳，提供 `/studio/appearance`、`/studio/motion`、`/studio/props` 和 `/studio/library` 四个路由。共享本地会话和资产选择，各编辑器内部状态独立。

## 结果

- 统一导航和上下文跳转；
- 外观、动作、道具和资产管理边界清晰；
- 继续复用唯一正式 Cloud Fox 渲染器；
- 路由刷新与浏览器历史可恢复工作区。

## 拒绝方案

- 单一超级页面；
- 三个完全独立的应用；
- 为每个工作区复制宠物渲染器。
