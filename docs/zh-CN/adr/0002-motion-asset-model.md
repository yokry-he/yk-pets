# ADR 0002：动作资产与语义 Rig

- 状态：Accepted

## 背景

云狐由程序化部件组成，底层 Mesh 和几何可能继续变化。将关键帧绑定到具体 Mesh、固定世界坐标或外观参数，会导致动作无法跨头型、身体和比例复用。

## 决策

- 动作使用稳定语义 Rig 通道，而不是底层 Mesh 路径；
- 时间以毫秒保存，界面可以显示 FPS 帧网格；
- 姿态保存为相对于基础外观挂点的局部偏移；
- 动作轨道不保存具体颜色、头型或身体形状；
- 内置三十动作保持只读，后续通过“创建可编辑副本”进入自定义资产；
- 插值、循环、淡入淡出和道具依赖属于动作资产。

## 结果

动作可以跨外观复用，底层渲染重构不会立即破坏资产。领域层必须先于时间轴 UI 完成，并拥有独立数值测试。

## 拒绝方案

- 固定帧数组作为唯一时间模型；
- 直接保存 Three.js Mesh 变换路径；
- 用外观静态配置充当动作姿态；
- 直接修改内置动作定义。
