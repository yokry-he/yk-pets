# ADR 0005：时间轴编辑与唯一正式预览适配器

- 状态：Accepted
- 日期：2026-07-25

## 背景

动作领域已经能够在任意毫秒求值完整 `EvaluatedCloudFoxPose`，但动作工坊尚无用户关键帧编辑和正式预览消费链路。

## 决策

1. 动作工坊使用独立草稿、撤销/重做、播放指针、选择集和剪贴板；草稿保存时才替换资产库中的 v2 动作。
2. 关键帧增删、复制、粘贴、移动和插值切换全部调用 `@yk-pets/pet-core` 的框架无关命令，并继续由规范化器解决重复时间和范围。
3. 每个动画帧只在动作页面求值一次，生成一个不可变语义姿态并沿 `CloudFoxStudioCanvas -> ProceduralPet -> ExtensionAlignedCloudFox` 传递。
4. 根节点、身体、头部、四肢、耳朵、眼嘴、尾巴和触角通过薄语义适配器消费；不得复制宠物拓扑或创建第二个长期 WebGL 场景。
5. 未写入通道保留既有呼吸、眨眼、视线和表情；已写入通道按语义覆盖或相对加成。
6. 三十个内置动作保持原运行时路径，不改为自定义关键帧资产。

## 后果

用户可以制作、保存和播放不含道具事件的自定义动作。道具事件、平滑/贝塞尔和曲线编辑留给后续阶段。真实浏览器迁移、GPU/WebGL 和像素结果仍需人工验收。
