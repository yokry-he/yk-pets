# ADR 0008：高级动画工具与安全本地资源

- 状态：Accepted
- 日期：2026-07-25

## 决策

1. 关键帧插值扩展为 `step`、`linear`、`smooth` 和带数值切线的 `bezier`。
2. 动作层按优先级执行 `override` 或 `additive`，每层具有启用、权重和中断策略。
3. 曲线编辑器、洋葱皮和运动轨迹只显示轻量语义标记，不复制云狐拓扑或创建第二个 TresCanvas。
4. 镜像、姿态预设和两段 IK 只生成语义关键帧，不修改外观配方。
5. 音效轨道支持本地音调和限额本地音频 data URL，不上传远程服务。
6. 本地 GLB 限制为 2 MB、GLB v2、长度一致、有效 JSON 块且禁止任何外部 URI；通过后使用 `GLTFLoader.parse` 在现有场景加载。

## 结果

阶段 E 的高级创作能力形成完整本地链路。真实浏览器音频授权、GPU/WebGL、复杂 GLB 和最终像素仍需人工验收。
