# ADR 0006：动作道具事件轨道

- 状态：Accepted
- 日期：2026-07-25

## 决策

1. 动作继续以稳定道具资产 ID 引用依赖，并用 `instanceId` 区分同一资产的多个运行时实例。
2. 事件集合固定包含 `create`、`show`、`attach`、`detach`、`move`、`hide`、`style`、`destroy`。
3. 事件使用整数毫秒，按时间和事件种类规范化；同一时间同一种类最后写入获胜。
4. 求值器按动作循环时间归约完整实例状态，包括挂点/世界空间、变换、颜色、透明度、发光和粒子速率。
5. 缺失依赖产生诊断但不触发网络请求或远程补全。
6. 道具实例在现有 `ExtensionAlignedCloudFox` 的同一个 TresCanvas 中渲染，不创建第二个场景。

## 后果

动作工坊可以制作确定性的持物、抛出、接住和效果事件。当前实例几何仍使用本地基础预览，道具实体编辑在下一阶段完成。
