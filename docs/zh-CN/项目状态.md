### Pet Studio

- `/studio/appearance`：完整外观和部件编辑；
- `/studio/motion`：schema v2 动作、毫秒时间轴、FPS 网格、关键帧、曲线、动作层、IK、音频、道具事件和直接操控；
- `/studio/props`：schema v2 道具实体、九类参数化组件、层级、材质、四个锚点、资源预算和安全本地 GLB；
- `/studio/library`：外观、内置/自定义动作和道具资产管理；
- 本地持久化、旧格式迁移、JSON 导入导出及依赖清理。

- `cloud-fox-semantic-rig/v1`；

## 5. 当前兼容边界

为避免破坏 `v0.6.10` 用户数据和通信，以下技术标识仍可能存在：

- `Nova*` 弃用类型别名；
- `NOVA_*` Wire Message；
- `@nova/*` 私有 Workspace scope；
- `nova:*` Storage Key 镜像；
- `.nova/agent.json` 迁移和补丁备份；
- `nova-agent` CLI 别名。

用户可见品牌、新领域模型和主 CLI 均使用 YK-PETS。兼容标识不得扩散到新公共 API。
