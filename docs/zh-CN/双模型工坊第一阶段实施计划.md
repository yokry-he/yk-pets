# 双模型工坊第一阶段实施计划

> **For agentic workers / 面向代理执行者：**实施时必须使用 `executing-plans`，逐项执行复选框；每项采用测试驱动开发，验证后使用中文提交信息并推送当前分支。

**Goal / 目标：**在不改变现有程序化简单模型正式渲染路径的前提下，建立同一宠物的双模型容器、全局模型模式、自动创建复杂草稿、跨工坊状态展示和兼容预览边界。

**Architecture / 架构：**新增纯 TypeScript 双模型领域契约和独立 Pinia 持久化 Store；Studio Session 只保存当前模型模式，不承载模型资产。统一 Studio 壳负责切换和自动创建复杂草稿，三个工坊通过 `CloudFoxStudioCanvas` 的模型模式适配入口继续使用简单模型兼容预览，为后续 GLB 骨骼渲染器保留明确边界。

**Tech Stack / 技术栈：**Nuxt 4、Vue 3、Pinia 4、TypeScript 5.9、TresJS 5、Three.js、Node.js 契约测试、现有 pnpm 工作区。

---

```ts
export type StudioModelMode = 'simple' | 'complex'
export type StudioModelVariantStatus = 'missing' | 'draft' | 'ready' | 'blocked'
export type ComplexModelCapability = 'renderer' | 'skeleton' | 'skin' | 'rig-mapping'

export interface StudioPetModelVariantsV1 {
  schemaVersion: 1
  petId: string
  simple: { kind: 'procedural'; status: 'ready'; updatedAt: number }
  complex: {
    kind: 'skinned'
    status: StudioModelVariantStatus
    completion: number
    pendingCapabilities: ComplexModelCapability[]
    createdAt?: number
    updatedAt: number
  }
}

export function createStudioPetModelVariants(petId: string, now = Date.now()): StudioPetModelVariantsV1
export function normalizeStudioPetModelVariants(
  input: unknown,
  fallbackPetId: string,
  options?: { now?: number; compilationTrust?: 'verify-persisted' | 'preserve-verified-memory' | 'discard-unverified' },
): StudioPetModelVariantsV1
export function createComplexModelDraft(input: StudioPetModelVariantsV1, now = Date.now()): StudioPetModelVariantsV1
```

`createComplexModelDraft` 只允许把 `missing` 变为 `draft`；已有 `draft`、`ready` 或 `blocked` 必须原样返回，禁止自动覆盖人工结果。

- [ ] **Step 3：实现归一化函数和独立 Pinia Store**

Store 状态与动作：

```ts
interface StudioModelVariantState {
  hydrated: boolean
  byPetId: Record<string, StudioPetModelVariantsV1>
}

actions: {
  hydrate(),
  persist(),
  ensurePet(petId: string),
  ensureComplexDraft(petId: string),
}
```

`hydrate` 捕获损坏 JSON 并回退空集合；`ensureComplexDraft` 复用纯领域函数，只有数据实际变化时才持久化。

- [ ] **Step 4：为 Studio Session 增加安全的 `modelMode`**

```ts
setModelMode(mode: StudioModelMode) {
  this.modelMode = normalizeStudioModelMode(mode)
  this.persist()
}
```
