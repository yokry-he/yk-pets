# 双足萌宠高级编舞与持械动作适配实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以“星云棍术组合”为纵向样板，在现有复杂双足运行时中加入版本化动作适配、双手持械约束、Motion/Pose Warping 和确定性武器轨迹特效，使新手复制动作后无需手工绑定即可直接得到可信结果。

**Architecture:** 现有长编排关键帧保留表演意图，`pet-core` 负责规范化并编译框架无关适配计划；Playground Three 适配层按固定所有权顺序把计划应用到 Root Motion、主手道具、副手手臂、足底 IK 和 VFX。所有增强均可局部降级，旧动作与旧道具继续按现有逻辑运行。

**Tech Stack:** TypeScript、Vue 3、Nuxt 4、Three.js、TresJS、Node.js Test Runner、现有 `@yk-pets/pet-core` Quaternion/IK/Root Motion/VFX 系统。

---

## 文件职责图

- `packages/pet-core/src/motion/biped-pet-motion-adaptation.ts`：动作适配扩展、计划编译和纯数值采样，不依赖 Three。
- `packages/pet-core/src/props/prop-rig.ts`：道具主副握点、轨迹端点和命中点的规范化与自动推导。
- `packages/pet-core/src/motion/biped-pet-motion-adapter.ts`：把动作适配扩展编入 Quaternion Clip，并在动作样本中暴露当前阶段与约束权重。
- `apps/playground/app/three/apply-complex-biped-weapon-constraint.ts`：主手固定、副手跟随的手臂 IK 控制器。
- `apps/playground/app/three/complex-biped-weapon-vfx.ts`：武器轨迹、火花和冲击环的固定对象池。
- `apps/playground/app/components/studio/ComplexBipedPropInstance.vue`：将已挂载道具的 Three Group 通过受控事件交给父级，不承担求解。
- `apps/playground/app/components/studio/ComplexBipedPetRenderer.vue`：统一创建、应用、重置和逆序释放动作、持械与 VFX 控制器。
- `apps/playground/app/components/studio/StudioMotionAdaptationSummary.vue`：面向新手的自动增强摘要与重新优化入口。
- `apps/playground/app/stores/studio-motion-editor.ts`：一次性恢复内置适配建议并产生一个撤销项。
