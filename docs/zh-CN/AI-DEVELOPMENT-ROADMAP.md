# AI 开发路线图

本路线图用于下一会话恢复开发顺序，不替代 GitHub 实时状态。每个阶段的功能提交必须同步更新 AI 交接包并通过完整 CI。

## 阶段 A：语义 Rig 与关键帧领域

目标：建立与具体 Three.js Mesh 解耦的动作数据层。

- 定义宠物根节点、身体、头部、前后爪、耳朵、眼睛、嘴巴、尾巴和触角的语义通道；
- 以毫秒保存时间，UI 可按 FPS 显示网格；
- 定义关键帧、轨道、插值、循环和归一化；
- 姿态保存为相对于外观默认挂点的偏移；
- 增加领域单元测试、旧资产迁移和越界检查。

完成标准：能够在无 UI 条件下创建动作资产、插入关键帧并在任意时间求值完整姿态。

## 阶段 B：时间轴编辑与正式预览

- 时间指针和播放控制；
- 自动关键帧与手动定格；
- 添加、删除、复制、移动和多选关键帧；
- 线性、平滑、保持和贝塞尔插值；
- 总时长缩放和循环接缝检查；
- 将求值结果接入唯一正式 Cloud Fox 预览。

完成标准：用户能制作、保存、刷新恢复并播放不含道具事件的完整自定义动作。

## 阶段 C：道具事件轨道

- 动作引用稳定道具 ID；
- 创建、显示、挂载、分离、移动、隐藏和销毁事件；
- 世界坐标和宠物挂点之间转换；
- 颜色、尺寸、发光和粒子事件；
- 缺失依赖和删除清理。

完成标准：可制作确定性的持物、抛出、接住和效果道具动作。

## 阶段 D：道具工坊实体编辑

- 参数化基础几何组合；
- 层级树与局部变换；
- 材质、颜色、透明度、金属度、粗糙度和发光；
- `origin`、`grip`、`display`、`emitter` 操纵器；
- 道具预览、复制、导入导出和资源预算。

完成标准：用户能创建不依赖远程资源的本地参数化道具，并在动作中稳定引用。

## 阶段 E：高级动画工具

- 曲线编辑器；
- 洋葱皮；
- 运动轨迹；
- 左右镜像与姿态预设；
- 动作分层和可中断策略；
- 可选 IK 辅助；
- 音效轨道；
- 经安全和性能评估后的本地 GLB 道具导入。

## 每阶段强制流程

1. 修改前核对 AI 包、代码、PR 和最新 CI；
2. 明确范围和验收标准；
3. 功能代码与 AI 包在同一提交；
4. 更新测试和架构门禁；
5. 运行完整 CI；
6. 全绿后更新 PR；
7. 保留真实浏览器和 WebGL 人工验收边界；
8. 未经明确要求不合并。
