# 已知问题与未完成边界

## MOTION-001：关键帧编辑尚未实现

- 状态：Open
- 现象：动作工坊显示资产、轨道名称和时间轴基础，但不能写入或移动关键帧。
- 禁止误解：时间轴刻度不代表自定义动作已经可以播放。
- 下一步：先完成语义 Rig、轨道和关键帧领域模型。

## MOTION-002：自定义动作运行时尚未实现

- 状态：Open
- 现象：预览继续播放现有内置动作，尚未求值自定义轨道。
- 风险：不能直接把外观静态配置当成动作姿态，否则会覆盖用户外观。
- 下一步：实现相对姿态求值和与基础呼吸、眨眼的混合规则。

- 当前约束：禁用按钮必须保持禁用，不能表现为已完成。
