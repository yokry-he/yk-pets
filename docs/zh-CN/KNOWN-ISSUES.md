# 已知问题与未完成边界

## MOTION-001：时间轴关键帧编辑尚未实现

- 状态：Open，领域基础已完成
- 已完成：schema v2 轨道与关键帧、程序化插入、排序、范围裁剪、重复时间处理、`step`/`linear` 插值和无 UI 求值。
- 尚未完成：用户不能在动作工坊中写入、移动、复制、删除或多选关键帧。
- 禁止误解：只读语义 Rig 轨道和领域插入函数不代表时间轴编辑已经可用。
- 下一步：建立独立编辑草稿、撤销语义、播放指针和关键帧操作。

## MOTION-002：自定义动作运行时尚未实现

- 状态：Open
- 现象：动作工坊预览继续播放现有待机动作，尚未消费 `EvaluatedCloudFoxPose`。
- 已完成基础：无 UI 求值器可以在任意毫秒输出完整语义姿态和实际写入通道。
- 风险：不能直接把外观静态配置当成动作姿态，否则会覆盖用户外观。
- 下一步：实现一次求值、多组件消费的姿态适配器，并定义与呼吸、眨眼和视线的混合规则。

## MOTION-003：高级插值和曲线编辑尚未实现

- 状态：Open
- 当前范围：仅支持 `step` 与 `linear`。
- 未完成：平滑、贝塞尔切线、曲线编辑器、洋葱皮和运动轨迹。
- 下一步：先完成基础时间轴与正式预览，再评估高级曲线工具。
