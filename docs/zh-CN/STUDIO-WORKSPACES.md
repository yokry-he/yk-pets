# 统一 Studio 工作区架构

YK-PETS Studio 使用同一个产品壳和四个独立路由：`/studio/appearance`、`/studio/motion`、`/studio/props`、`/studio/library`。`/studio` 只兼容跳转。四个工作区共享本地资产选择、视角和背景，但各编辑器撤销栈独立。

## 资产边界

- 外观：基础结构、颜色和静态默认姿态；
- 动作：相对语义姿态、毫秒时间、循环、插值和道具依赖；
- 道具：资产类型、默认挂载、组件层级和锚点。

动作不得修改外观配方；动作引用稳定道具 ID，不直接修改道具定义。

## 当前能力

- 完整外观工坊无损迁移；
- 动作资产 v2、独立草稿、撤销重做、播放指针和播放控制；
- 关键帧写入、删除、复制、粘贴、移动、多选和 `step`/`linear`；
- 每帧一次语义姿态求值并通过唯一正式 Cloud Fox 渲染器预览；
- 道具资产、类型、默认挂载、锚点和层级基础；
- 资产库查看、上下文编辑和删除。

## 尚未完成

道具事件轨道、同场景实例预览、版本化组件树、几何、材质和内部锚点编辑已经完成。高级动画工具仍未完成；后续必须继续复用唯一正式渲染器，不能复制宠物拓扑或新增长期 WebGL 场景。

## 安全边界

没有新增 Chrome 权限、网络上传、后台轮询、WebSocket 或宿主网页持久配置 DOM。
