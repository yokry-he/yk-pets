# 表情与动态动作扩展实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在统一 Cloud Fox 渲染器上增加丰富眼鼻造型、可逐帧编辑的动作安全形变、只读内置道具，以及舞蹈、功夫和灵动运动动作模板。

**架构：** 基础外观继续由外观配方负责，动作资产只保存语义 Rig 数值轨道；新增形变通道以中性值叠加到基础外观。内置动作和道具使用独立不可变注册表，用户复制后才进入 Pinia 本地资产存储。

**技术栈：** TypeScript、Vue 3、Nuxt 4、Pinia、TresJS/Three.js、Node.js 契约检查、Node Test Runner、pnpm。

---

## 文件结构

- `packages/pet-core/src/motion/cloud-fox-rig.ts`：扩展动作安全语义通道及范围。
- `packages/pet-core/src/motion/motion-controls.ts`：把新通道组织成动作部件与编辑控件。
- `packages/pet-core/test/motion-system.test.ts`：验证中性值、范围、插值和旧动作兼容。
- `apps/playground/app/domain/pet-studio-phase2.ts`：注册新增眼睛和鼻子静态造型。
- `apps/playground/app/components/studio/ExtensionCloudFoxEyeShape.vue`：渲染新增眼型。
- `apps/playground/app/components/studio/ExtensionCloudFoxHead.vue`：应用眼睛动作形变。
- `apps/playground/app/components/studio/ExtensionCloudFoxFaceCustomization.vue`：渲染新鼻型并应用鼻部动作形变。
- `apps/playground/app/components/studio/ExtensionAlignedCloudFox.vue`：把安全形变传入身体、头部、耳尾和面部节点。
- `apps/playground/app/domain/studio-built-in-props.ts`：定义只读内置道具注册表。
- `apps/playground/app/domain/studio-built-in-motions.ts`：定义只读内置动作模板和道具事件。
- `apps/playground/app/stores/studio-assets.ts`：提供复制内置资产为用户资产的命令。
- `apps/playground/app/pages/studio/library.vue`：展示、预览和复制内置动作、道具。
- `apps/playground/app/pages/studio/motion.vue`：让内置道具参与动作预览并提供模板入口。
