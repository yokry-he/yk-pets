# 双足萌宠语义动作编译实施计划

> 实施状态（2026-07-28）：第一阶段已完成并通过自动验证与 Chrome 1440×900、760×900 功能验收。运行时 IK、足底锁定、完整 Root Motion、复杂动作/特效和最终图形质量属于下一阶段。

> **面向代理开发者：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 按任务执行；所有步骤使用复选框跟踪。

**目标：** 将动作工坊语义动作确定性编译为 `biped-pet/v1` 骨骼 Quaternion Clip，内置五个基础动作，并让复杂 Three 运行时支持播放、暂停、拖动与停止恢复。

**架构：** `@yk-pets/pet-core` 新增无框架的 Quaternion 数学、动作适配、Clip 编译和采样模块；Playground 新增基础动作资产和很薄的 Three 骨骼应用器。`CloudFoxStudioCanvas` 继续是唯一画布，简单模型保留原有 `customPose`，复杂模型消费同一动作资产编译出的 Clip。

**技术栈：** TypeScript、Node Test Runner、Vue 3、Nuxt 4、Three.js、TresJS、现有 `@yk-pets/pet-core` Motion/Rig 契约。

---

- [ ] **步骤 3：实现完整动作编译和采样**

`compileBipedPetMotion()` 接收可选 `BipedPetMotionCompileTarget`，先调用现有 `normalizeMotionAsset()`，收集 0、`durationMs` 和全部关键帧时间；逐时间调用 `evaluateNormalizedMotionAsset()` 与姿态适配器；按当前真实 `boneIds` 聚合关键帧，去除相邻重复值，并使用不包含 `updatedAt` 的稳定序列化生成 hash。

`sampleBipedPetMotion()` 必须调用现有 `resolveMotionTime()`，对根位移线性插值，对旋转用 `slerpMotionQuaternion()`；`blocked` Clip 返回空骨骼和零根位移。

```ts
export interface SampledBipedPetMotion {

  bones: readonly { boneId: string; rotation: MotionQuaternion }[]
  rootPosition: RigVector3
  activeContacts: readonly string[]
```
