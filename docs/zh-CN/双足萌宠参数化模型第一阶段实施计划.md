# 双足萌宠参数化模型第一阶段实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `biped-pet/v1` 站内参数化复杂模型闭环，让用户无需导入模型、创建骨架或绘制权重，即可从模型配方生成可持久化、可编辑并能在统一 Studio Canvas 中渲染的双足萌宠复杂模型。

**Architecture:** 在 `@yk-pets/pet-core` 中新增不依赖 Vue、Three.js 和 GPU 的 Rig Profile、模型配方与角色编译器；编译器输出骨架、程序化网格、蒙皮权重、关节限制、接触点、Socket 和诊断。Playground 只负责把编译结果转换为 Three.js `SkinnedMesh`、持久化配方，并在复杂模式下使用新的渲染适配器。为控制单批风险，本计划完成模型与自动绑定基础；五个语义动作和动作生成器紧接本批以独立计划实施。

**Tech Stack:** TypeScript 5.9、Node.js Test Runner、Vue 3、Nuxt 4、Pinia、Three.js、TresJS、现有 `CloudFoxStudioCanvas`

- [ ] **Step 4: 实现确定性骨架与网格算法**

实现顺序固定为：规范化配方 → 生成基础骨架 → 插入启用的可选链 → 为躯干、左右上肢和左右下肢追加渐变管段 → 追加头部刚性顶点区 → 生成索引 → 计算权重 → 诊断 → 稳定哈希。

每个管段使用 8 个径向顶点、4 个轴向分段。对轴向参数 `t`：

```ts
const endWeight = smoothstep(0.18, 0.82, t)
const startWeight = 1 - endWeight
skinIndices.push(startBoneIndex, endBoneIndex, 0, 0)
skinWeights.push(startWeight, endWeight, 0, 0)
```

`appendTaperedBoneTube()` 必须根据骨骼起终点构造稳定正交基；当骨骼方向与默认 Up 平行时改用 X 轴作为参考，避免叉乘零向量。头部顶点全部绑定头骨；手脚末端分别绑定手部和脚掌骨。

稳定哈希只输入规范化配方、Profile ID、生成器版本和编译数组，不包含当前时间、对象地址或随机数。

- [ ] **Step 2: 实现编译结果到 Three.js 对象的转换**

`createComplexBipedPetObject(compiled, colors)` 必须：

1. 创建 `BufferGeometry` 并安装 `position`、`skinIndex`、`skinWeight` 与 index；
2. 调用 `computeVertexNormals()`、`computeBoundingBox()` 和 `computeBoundingSphere()`；
3. 按编译顺序创建 `Bone`，使用 `parentIndex` 建立层级；
4. 创建 `Skeleton`、`MeshStandardMaterial` 和 `SkinnedMesh`；
5. 把 Root Bone 加入 SkinnedMesh 后调用 `bind(skeleton)`；
6. 返回 `{ object, bonesById, sockets, dispose }`；
7. `dispose()` 释放 geometry、material 和 skeleton，且可重复调用。

使用 `Uint16BufferAttribute` 保存 skinIndex，使用 `Float32BufferAttribute` 保存 position/skinWeight。禁止在 Vue 响应式对象中深度代理 Three.js 实例。

import { compileBipedPetCharacter, type CharacterModelRecipeV1 } from '@yk-pets/pet-core'
