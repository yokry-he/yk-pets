# 默认形象局部继承设计

## 背景

用户提供了在外观工坊中手动调整并导出的 `zeph-appearance-v4.json`，希望把其中的头身比例、肩部、尾巴和手臂展开角度设为云灵默认形象。其余脸型、表情、颜色、发光、肚皮、标志、触角、肢体长度和爪掌尺寸不应随导入文件变化。

## 目标

- 新建、重置和经典外观预览统一使用新的默认形体。
- 仅继承明确授权的形体字段，不把整份导出文件写入生产默认值。
- 继续通过现有标准化流程生成完整且兼容的 `MultiSpeciesAppearanceRecipe`。
- 不修改现有用户已经保存的本地外观资产。

## 字段白名单

### 头身比例

| 字段 | 新默认值 |
| --- | ---: |
| `proportions.bodyWidth` | `0.85` |
| `proportions.bodyHeight` | `0.77` |
| `proportions.bodyDepth` | `1` |
| `proportions.headScale` | `1.24` |

`bodyScale` 保持 `1`；头型保持当前默认的 `classic-round`，不继承导出文件中的 `wide-round`。

### 肩部与手臂角度

| 字段 | 新默认值 |
| --- | ---: |
| `frontPawDesign.rootHeight` | `0.1` |
| `frontPawDesign.embedDepth` | `0.25` |
| `frontPawDesign.forwardOffset` | `-0.13` |
| `frontPawDesign.lateralOffset` | `0.28` |
| `frontPawDesign.shoulderScale` | `1.62` |
| `frontPawDesign.outwardAngle` | `0.55` |
| `frontPawDesign.forwardAngle` | `0.1` |

前爪样式继续使用 `soft`；手腕粗细、爪掌大小、左右独立偏移、肢体长度、肢体粗细和爪子整体大小保持当前默认值。

### 尾巴比例与几何

| 字段 | 新默认值 |
| --- | ---: |
| `proportions.tailLength` | `1.36` |
| `proportions.tailWidth` | `0.9` |
| `tailDesign.rootOffsetX` | `0` |
| `tailDesign.rootOffsetY` | `-0.21` |
| `tailDesign.rootOffsetZ` | `0.09` |
| `tailDesign.rootExtensionLength` | `0.12` |
| `tailDesign.rootExtensionWidth` | `0.15` |
| `tailDesign.lateralOffset` | `-0.03` |
| `tailDesign.direction` | `left` |

尾段使用导出文件中的三段几何：

1. 长 `0.7`、宽 `0.16`、X 偏移 `0.01`、Y 旋转 `-0.061592653589793`、Z 旋转 `-0.081592653589793`。
2. 长 `0.58`、宽 `0.16`、Z 旋转 `0.1`。
3. 长 `0.52`、宽 `0.16`、Z 旋转 `0.16`。

未列出的尾段偏移与旋转均为 `0`。尾尖发光的颜色、强度和光晕保持当前项目默认值，不从导出文件继承。

## 实现方式

直接更新 `createExtensionClassicAppearance()` 中上述白名单字段。该工厂已经被 Studio 初始化、恢复经典外观、视觉审计和扩展统一渲染链复用，因此不新增第二套默认配方，也不修改标准化器。

先在现有 TypeScript 回归测试中写入白名单断言和非白名单保留断言，观察测试因旧默认值失败，再修改工厂值使测试通过。视觉结构门禁同步锁定新默认值，防止以后无意回退。

## 兼容与迁移

- 新安装、无本地配方、点击恢复经典外观和经典对比预览会使用新默认形体。
- 已保存到本地的外观配方保持原值，不进行覆盖或自动迁移。
- JSON schema、导入导出格式和扩展消息协议均不变化。
- 如需回滚，只需恢复工厂白名单字段；无需迁移用户数据。

## 验证标准

- 自动测试确认所有白名单字段等于导出文件对应值。
- 自动测试确认 `headShape`、眼睛、嘴型、颜色、手腕、爪掌和尾尖发光仍为当前经典默认值。
- 全量类型检查和 Playground 生产构建通过。
- 浏览器中清除当前外观到经典默认状态后，正面检查头身与肩臂轮廓，侧面和背面检查尾根及三段尾巴走向。
