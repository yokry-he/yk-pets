# 复杂模式切换入口临时隐藏设计

## 背景

当前阶段暂停复杂模型功能开发，后续工作集中在简单模式的动作工坊。Studio 顶部仍显示“简单模型 / 复杂模型”切换按钮，容易让用户进入暂不继续完善的复杂模式。

## 目标

- 临时隐藏 Studio 顶部的简单/复杂模型切换入口。
- 不改变当前模型模式的状态结构、持久化数据或渲染能力。
- 不删除复杂模型组件、配方、资产和测试，为后续恢复保留完整实现。

## 方案

在 `apps/playground/app/layouts/studio.vue` 增加局部、只读的显示开关，并让 `StudioModelModeSwitch` 仅在该开关开启时渲染。当前开关固定关闭，因此顶部不再出现两个切换按钮；原组件、事件处理和模型模式数据流继续保留。

本次不强制把已持久化的 `complex` 状态改成 `simple`，不清理浏览器存储，也不改动复杂模型自动草稿、渲染器或资产库信息。这保证改动严格属于“隐藏入口”，不会对已有数据产生迁移副作用。

## 测试与验收

- 更新 Studio 模型模式静态门禁，要求布局包含关闭状态的入口显示开关，并继续保留切换组件和双模型底层契约。
- 先让新门禁在现有实现上失败，再修改布局使其通过。
- 运行 Studio 模型模式门禁、工作区壳门禁、Playground 类型检查和生产构建。
- 在浏览器中检查外观工坊和动作工坊顶部均不再显示模型模式切换入口，同时页面无新增控制台错误。

## 回滚方式

把布局内的显示开关恢复为开启即可重新显示原切换器，不需要恢复组件或迁移数据。
