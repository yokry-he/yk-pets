# 默认形象局部继承实施计划

> **面向自动化开发者：** 必须使用 `executing-plans` 或 `subagent-driven-development` 按任务逐项实施；每一步使用复选框跟踪。当前会话按用户连续执行偏好采用 `executing-plans`。

**目标：** 把 `zeph-appearance-v4.json` 中已批准的头身比例、肩部结构、手臂角度和尾巴几何设为云灵默认形象，同时保留所有非白名单经典默认值。

**架构：** 继续由 `createExtensionClassicAppearance()` 作为唯一默认外观工厂，只修改设计文档列出的字段。现有标准化、Studio 初始化、恢复经典外观、视觉审计与扩展统一渲染链无需新增分支。

**技术栈：** TypeScript、Vue 3、Nuxt 4、TresJS、Node.js `assert`、静态结构门禁。
