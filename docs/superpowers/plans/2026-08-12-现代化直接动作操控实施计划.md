# 现代化直接动作操控实施计划

> **面向自动化开发者：** 必须使用 `executing-plans` 逐任务实施；步骤使用复选框跟踪。当前会话不主动分派子代理。

**目标：** 在简单模式动作工坊中交付“点击 3D 部位→选择移动或旋转→直接拖拽→姿势卡或参数微调”的现代化动作设计流程。

**架构：** `pet-core` 新增版本化但不持久化的直接操控能力注册表、姿势卡和纯函数拖拽求解器；Pinia Store 使用已有 `controlGestureBaseline` 将连续预览收敛为一次阶段事务；唯一 `CloudFoxStudioCanvas` 提供语义拾取坐标，页面上的操控覆盖层负责指针仲裁；右侧固定部位属性栏与浮动工具共享 Store 状态。现有 `StudioMotionAssetV2`、阶段扩展、编译器、高级编辑和自动保存链路保持不变。

**技术栈：** TypeScript、Vue 3、Nuxt 4、Pinia、Three.js、TresJS、Node.js Test Runner、CSS Grid、现有 YK-PETS 语义 Rig、Two Bone IK/FABRIK 与 `StudioMotionAssetV2`。

```ts
export interface DirectMotionDragInput {
  partId: MotionBodyPartId
  mode: DirectMotionMode
  delta: Readonly<{ x: number; y: number; depth: number }>
  viewport: Readonly<{ width: number; height: number }>
  pose: Readonly<Partial<Record<MotionControlId, number>>>
}

export interface DirectMotionSolveResult {
  status: 'ready' | 'clamped' | 'blocked'
  pose: Readonly<Partial<Record<MotionControlId, number>>>
  diagnostics: readonly string[]
}

export function solveDirectMotionDrag(input: DirectMotionDragInput): DirectMotionSolveResult {
  const capability = getDirectMotionCapability(input.partId)
  if (!capability || !capability.modes.includes(input.mode)) return blockedResult(input.pose, '该部位暂不支持此操作。')
  if (![input.delta.x, input.delta.y, input.delta.depth, input.viewport.width, input.viewport.height].every(Number.isFinite)) return blockedResult(input.pose, '拖拽输入无效。')
  // 以视口短边归一化屏幕位移，映射到该部位声明的语义控制；每个结果通过控制安全范围钳制。
  return solveRegisteredControls(input, capability)
}

export function applyDirectMotionPoseCard(
  pose: Readonly<Partial<Record<MotionControlId, number>>>,
  cardId: string,
): DirectMotionSolveResult
```

手脚移动首期通过既有旋转语义控制形成确定性末端近似：水平/垂直拖动映射肩或髋的 `rotate.z/x`，深度映射 `rotate.y`，爪尖弯曲作为辅助控制；必须使用每个控制已注册的安全范围。不得新增虚构的 `front-paw.translate.*` 控制，也不得通过缩放肢体伪造可达目标。复杂模型的真实 IK 继续由运行时消费同一语义姿势。

- [ ] **步骤四：实现拖拽事务和姿势卡命令**

```ts
beginDirectManipulation(pointerId: number, x: number, y: number) {
  const stage = this.selectedSimpleStage
  if (!stage || this.authoringMode !== 'guided') return false
  this.beginControlGesture()
  this.directManipulation = { active: true, pointerId, startX: x, startY: y, depth: 0, baselinePose: { ...stage.pose }, status: 'ready' }
  return true
},
previewDirectManipulation(pointerId: number, x: number, y: number, viewport: { width: number; height: number }, depth = 0) {
  if (!this.directManipulation.active || pointerId !== this.directManipulation.pointerId) return
  const result = solveDirectMotionDrag({
    partId: this.selectedBodyPartId,
    mode: this.directManipulationMode,
    delta: { x: x - this.directManipulation.startX, y: y - this.directManipulation.startY, depth },
    viewport,
    pose: this.directManipulation.baselinePose,
  })
  this.previewSimpleStagePose(result.pose)
  this.directManipulation.status = result.status
},
commitDirectManipulation(pointerId: number) {
  if (!this.directManipulation.active || pointerId !== this.directManipulation.pointerId) return
  this.directManipulation.active = false
  this.endControlGesture()
},
cancelDirectManipulation() {
  this.directManipulation.active = false
  this.cancelControlGesture()
},
applyDirectPoseCard(cardId: string) {
  const stage = this.selectedSimpleStage
  if (!stage) return
  const result = applyDirectMotionPoseCard(stage.pose, cardId)
  if (result.status !== 'blocked') this.updateSimpleStage(stage.id, { pose: result.pose })
},
setDirectManipulationMode(mode: DirectMotionMode) {
  const capability = getDirectMotionCapability(this.selectedBodyPartId)
  if (capability?.modes.includes(mode)) this.directManipulationMode = mode
},
resetSelectedDirectPart() {
  const stage = this.selectedSimpleStage
  const capability = getDirectMotionCapability(this.selectedBodyPartId)
  if (!stage || !capability) return
  const pose = { ...stage.pose }
  for (const controlId of capability.controlIds) delete pose[controlId]
  this.updateSimpleStage(stage.id, { pose })
},
```

`previewSimpleStagePose` 必须复用 `controlGestureBaseline` 中的动作资产重编译预览，不能为每个 `pointermove` 调用 `snapshot()`。语义滑杆和精确输入继续调用 `writeControlValue`，因此与拖拽共享同一 `stage.pose`。
