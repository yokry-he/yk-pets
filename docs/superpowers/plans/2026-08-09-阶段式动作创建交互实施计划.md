# 阶段式动作创建交互实施计划

> **面向自动化开发者：** 必须使用 `executing-plans` 逐任务实施；步骤使用复选框跟踪。

**目标：** 把简单模式动作工坊改造为“选择动作意图→调整阶段姿势→直接播放”的新手流程，同时保留现有专业编辑能力。

**架构：** `pet-core` 新增版本化阶段配方和确定性编译器，产出现有 `StudioMotionAssetV2`；Pinia 编辑 Store 管理阶段选择和事务式重编译；动作页默认显示意图卡、阶段条与简化属性，现有时间轴、通道、曲线、动作层和道具事件收入高级编辑。

**技术栈：** TypeScript、Vue 3、Nuxt 4、Pinia、Node.js Test Runner、CSS Grid、现有 YK-PETS 语义 Rig 与 `StudioMotionAssetV2`。

```ts
createMotionFromIntent(intent: SimpleMotionIntent, authoringAppearanceId?: string) {
  const now = Date.now()
  const recipe = createSimpleMotionRecipe(intent)
  const definition = SIMPLE_MOTION_INTENTS.find(item => item.id === intent)!
  const seed = createStudioMotionAsset({
    id: createStudioAssetId('motion'),

    nameEn: definition.defaultNameEn,
    authoringAppearanceId,
    createdAt: now,
    updatedAt: now,
  })
  const motion = compileSimpleMotionRecipe(seed, recipe, { now }).asset
  this.motions.unshift(motion)
  this.persist()
  return motion
}
```

```ts
updateSimpleRecipe(mutator: (recipe: SimpleMotionRecipeV1) => SimpleMotionRecipeV1) {
  if (!this.draft) return false
  const current = readSimpleMotionRecipe(this.draft)
  if (!current) return false
  const nextRecipe = normalizeSimpleMotionRecipe(mutator(current)).value
  const compiled = compileSimpleMotionRecipe(this.draft, nextRecipe)
  this.snapshot()
  this.apply(compiled.asset)
  this.selectedStageId = nextRecipe.stages.some(stage => stage.id === this.selectedStageId)
    ? this.selectedStageId
    : nextRecipe.stages[0]?.id || ''
  return true
}
```

```ts
let autoSaveTimer: ReturnType<typeof setTimeout> | undefined
function scheduleAutoSave() {
  if (!editor.isDirty) return
  editor.setSaveState('saving')
  clearTimeout(autoSaveTimer)
  autoSaveTimer = setTimeout(() => {
    try { saveCurrent(''); editor.setSaveState('saved') }
    catch { editor.setSaveState('failed') }
  }, 500)
}
function flushAutoSave() {
  clearTimeout(autoSaveTimer)
  if (editor.isDirty) saveCurrent('')
}
```
