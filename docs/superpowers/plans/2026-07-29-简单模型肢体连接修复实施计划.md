# 简单模型肢体连接修复实施计划

> **面向自动化开发者：** 必须按任务顺序执行；每个行为先完成失败测试，再实施最小修复。

**目标：** 修复简单模型肩部与身体分离、腿段与脚掌断开的结构性问题。

**架构：** 新增框架无关的肢体装配纯函数，统一推导肩部连接体和踝脚链。Vue/Tres 组件只消费装配结果，现有动作数据继续驱动上层动作组。

**技术栈：** TypeScript、Vue 3、Nuxt 4、TresJS、Three.js、Node.js `assert` 回归测试。
